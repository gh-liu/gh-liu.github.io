A 收集器通常用引用计数或从根集合出发的可达性追踪判断对象存活，再以清扫、压缩或复制回收空间；分代、分区、增量和并发技术缩小每次工作量或把工作与应用并行，但需要屏障维护正确性。

1. GC 管理的是什么

操作系统管理虚拟页和物理页，不知道语言对象之间的引用关系；GC 是语言运行时中的对象级内存管理。参与者包括：

  • mutator：应用线程，分配对象并修改引用。
  • allocator：从托管 heap 中寻找可用空间。
  • collector：识别不可达对象并回收空间。

GC 通常能可靠识别的是“从根集合不可达”的对象。一个对象即使以后永远不会使用，只要仍然可达，普通追踪 GC 也不会知道它是语义垃圾。

根集合常包括线程栈、寄存器、全局变量和运行时内部引用。准确范围取决于语言和运行时。

2. 评价指标

  • 吞吐量：总时间中用于执行应用工作的比例。
  • 暂停时间：应用线程因 GC 停止的单次时长及其尾延迟。
  • 内存开销：为半空间、标记位图、卡表、转发表和保留空闲空间付出的成本。
  • 分配与回收速度：快路径是否只需移动指针，回收是否需要扫描整个 heap。
  • 碎片：空闲总量足够，但缺少所需大小的连续空间。

这些目标相互冲突。低暂停收集器通常需要更多并发 CPU、屏障开销和额外内存；高吞吐收集器可以接受更长的批量暂停。

3. 基础算法

引用计数

每个对象记录指向它的引用数；引用数变为 0 时立即释放。

优点是回收及时、工作分散；主要问题是：

  • 普通引用计数无法自行回收循环引用。
  • 每次引用更新都要维护计数。
  • 释放一个对象可能递归减少大量子对象的计数，形成延迟尖峰。

实现可以结合循环检测、弱引用或延迟批处理缓解这些问题。

标记—清扫（mark-sweep）

  1. 从根集合遍历引用图，标记所有可达对象。
  2. 扫描 heap，回收未标记对象。

它不移动存活对象，因此指针稳定，但容易产生碎片。标记信息可存入对象头或独立位图；独立位图还能避免只因 GC 标记而改写对象所在页。

标记—压缩（mark-compact）

完成标记后移动存活对象，使其连续排列，并修复指向这些对象的引用。它消除外部碎片，但移动和指针修复成本更高，也要求运行时能准确找到引用。

复制收集（copying collection）

把存活对象从 from-space 复制到 to-space，使用转发地址避免重复复制，并在遍历过程中修复引用。复制后空闲区域天然连续，分配可使用 bump pointer。

经典半空间算法会保留一块等大的 to-space，空间利用率较低；实际收集器也可以按 region 选择性复制，而不必把整个 heap 永久一分为二。

4. 分代与分区

分代收集

分代假设是“大多数对象朝生夕死”。新对象进入年轻代，经历若干次收集仍存活后晋升到老年代：

  • 年轻代通常使用复制算法，只扫描较小区域。
  • 老年代收集频率较低，可使用标记—清扫或标记—压缩。

只扫描年轻代时仍必须找到老年代到年轻代的引用。写屏障把相关地址记录到 remembered set 或 card table，避免每次扫描整个老年代。

Region-based 收集

heap 被切成多个 region，收集器可以优先处理垃圾比例高的区域，并把存活对象复制到其他区域。这把“整代回收”细化为区域级选择，在暂停目标和碎片整理之间提供更多调节空间。

5. 三色标记

三色抽象描述一次追踪过程中的对象状态：

  • 白色：尚未发现；标记结束后仍为白色的对象可回收。
  • 灰色：已发现，但它指向的对象尚未全部扫描。
  • 黑色：已发现，且它指向的对象已经扫描完。

算法从灰色根开始，反复扫描一个灰色对象，把它引用的白色对象染灰，再把自身染黑；没有灰色对象时结束。

颜色只表示当前标记周期的扫描状态，不能简单把“白色”始终等同于垃圾。并发标记期间 mutator 仍会修改引用图，收集器必须防止一个实际可达的白色对象被漏标。

6. 增量、并发与屏障

  • 增量收集把长任务切成多个时间片，降低单次暂停。
  • 并发收集让 collector 与 mutator 在不同 CPU 上同时执行，减少 stop-the-world 时间。

两者都使引用图在标记期间发生变化，因此需要读屏障或写屏障维护不变式。这里的 GC barrier 是插入到对象引用读写路径的一段运行时代码，不要和 CPU memory barrier 混为一谈。

7. 分配器与收集器的配合

  • 线性/bump-pointer 分配速度快，但要求回收后能得到连续空闲区域，常与复制或压缩算法配合。
  • 空闲链表保存可复用内存块，可使用 first-fit、best-fit 或 segregated-fit 等策略，但要处理查找成本和碎片。
  • size class 把相近大小对象分组，使常见小对象可在固定大小槽位中快速分配。

对象头、对齐空隙、标记位图和预留空间都属于运行时内存开销。收集器设计不能脱离分配器单独评估。
