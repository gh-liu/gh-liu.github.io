Q 阅读一小段 x86 汇编需要掌握哪些最小概念？

A 先分清寄存器类别和位宽，再理解操作数如何寻址、比较如何设置标志位、跳转如何消费标志位，以及调用约定如何组织参数、返回值和栈帧。

1. 寄存器

x86 寄存器大致分为：

  • 通用寄存器：参与算术、逻辑、地址计算和参数传递，例如 RAX、RBX、RCX、RDX。
  • 指令指针：RIP 指向下一条待执行指令。
  • 栈指针：RSP 指向当前栈顶。
  • 基址寄存器：RBP 可用作栈帧基址，但优化编译时常被当作普通寄存器使用。
  • 标志寄存器：保存零、进位、符号、溢出等条件标志。
  • 段寄存器：CS、SS、DS、ES、FS、GS；在现代 x86-64 平坦模型中，大部分传统分段作用已经弱化，FS/GS 仍常用于线程本地存储等场景。

寄存器名称还表达位宽和局部区域。例如 RAX 是 64 位，EAX 是低 32 位，AX 是低 16 位，AL 是低 8 位。写入 EAX 会把 RAX 高 32 位清零，这是 x86-64 的重要规则。

4. 数据定义（NASM）

NASM 中，DB / DW / DD / DQ 分别定义 1、2、4、8 字节数据。RESB / RESW / RESD / RESQ 为未初始化数据预留对应宽度的空间，TIMES 用于重复数据定义。

这些是汇编器 directive，不是 CPU 指令。它们描述目标文件中的数据布局。

5. 调用约定

调用约定（ABI）规定参数放在哪些寄存器、返回值放在哪里、哪些寄存器由调用者或被调用者保存，以及栈如何对齐。它由平台决定，不能只凭 CPU 架构推断：x86-64 System V ABI 和 Windows x64 ABI 就不同。

系统调用还有独立 ABI；不同操作系统、位数和 CPU 模式使用的陷入指令与参数寄存器可能不同，详见 syscall。
