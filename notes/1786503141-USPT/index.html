组件

可以先把大语言模型理解成一条“文字 → 数字 → 处理 → 文字”的流水线：

  1. Tokenizer 把文本切成 token，Embedding 把 token 变成向量；
  2. Transformer Block 反复结合上下文更新这些向量；
  3. LM Head 再把最终向量转换成词表中每个 token 的分数，Sampling 根据分数选出下一个 token。

在 Transformer Block 内，Attention 负责让不同 token 交换信息，MLP 负责进一步加工每个 token 的信息；Residual 和 Norm 则帮助信息稳定地流过很多层。模型在每一层产生的 token 表示称为 hidden state（隐藏状态）。

以主流 decoder-only Transformer LLM 为例：

Position / RoPE token 向量、位置 带位置信息的表示 让模型知道 token 的顺序和相对位置

  1. Tokenizer（分词器）：文本世界 → Token 世界。把文本切分并转换成模型词表中的 token ID。
  2. Embedding（嵌入层）：Token 世界 → 向量世界。把每个 token ID 转换成模型能够计算的初始向量。
  3. Position / RoPE（位置信息）：告诉模型“谁在前、谁在后”，让 Attention 能感知 token 的顺序和相对位置。
  4. Transformer Block（核心处理模块）：由 Attention、MLP、Residual 和 Norm 等组件组成。多个 Block 串联起来，逐层更新模型对每个 token 的表示。
  5. Norm（归一化）：把 hidden state 的数值控制在合适范围内，让深层网络的训练和推理更稳定。
  6. Attention（注意力）：让 token 从上下文中的其他 token 获取信息。Q/K/V 可以直观理解为“我想找什么 / 我能否被匹配 / 我能提供什么”。
  7. Causal Mask（因果掩码）：生成当前 token 时不能偷看后面的 token，保证模型只能根据已有内容预测下一个 token。
  8. Multi-Head Attention（多头注意力）：并行使用多组 Attention，让模型可以从不同角度理解上下文关系。
  9. Residual（残差连接）：把原有信息保留下来，再叠加本层学到的新信息，使模型可以逐层修改而不必每层重建表示。
  10. MLP / FFN（前馈网络）：单独加工每个 token 的信息，通过非线性变换提取和组合新的特征。
  11. Hidden State（隐藏状态）：模型在某一层对每个 token 的当前表示，也是各层之间持续传递和更新的数据。
  12. Final Hidden State（最终隐藏状态）：经过最后一个 Transformer Block 后得到的 token 表示。
  13. LM Head（语言模型输出层）：把最终隐藏状态转换为词表中每个 token 的分数。
  14. Logits / Sampling（分数与采样）：logits 是候选 token 的原始分数；采样策略根据这些分数选出下一个 token。
  15. KV Cache（键值缓存）：保存历史 token 已经算出的 K/V，用更多显存换取更少的重复计算，从而加快逐 token 生成。

Tokenizer = 切分 Embedding = 表示 Position = 定位 Attention = 读取 / 通信 MLP = 加工 / 计算 Residual = 保留 + 累积 Norm = 稳定 Hidden State = 模型当前内部状态 LM Head = 翻译成词表分数 Sampler = 决策下一个 token KV Cache = 记住历史计算结果
