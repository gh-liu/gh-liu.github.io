Go: profiling 性能分析

当面对内存泄漏、CPU占用过高等性能问题时，使用golang提供的pprof工具进行性能分析，快速定位性能问题。

Profile 的 sample 结构、profile 类型、采样机制、runtime/pprof API 与 net/http/pprof 采集端点见 Go: 标准库 pprof。本文从已有 profile 出发，负责 go tool pprof 的展示与诊断流程。
