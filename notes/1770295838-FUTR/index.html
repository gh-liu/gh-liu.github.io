A future is a value that may not be ready now but will become ready at some point in the future. Represents an eventual result of an asynchronous operation.

python

Future 是结果槽，类似 Promise

Future 用来 bridge low-level callback-based code 与 high-level async/await code。

rust

Future 是 lazy 的计算状态机：一个还没跑完的计算对象 + 这个计算当前执行到哪儿的状态

lazy: 除非你 .await、poll 或把它交给 executor，否则它不会推进。

.await 本质更接近：不断问 Future 你现在完成了吗？。Rust 把这个过程叫 polling。

为什么 Future 能 suspend？Rust 编译器会把 async 函数编译成类似 enum 的一个状态机

谁来 poll Future？Executor 负责推进 async computation 的部分。Reactor 负责唤醒wait的任务。
